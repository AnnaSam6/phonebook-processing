# Обработка адресной книги

## Описание проекта
Программа для приведения в порядок адресной книги с использованием регулярных выражений.

## Задачи
1. **Обработка ФИО** - распределение фамилии, имени и отчества по правильным полям
2. **Форматирование телефонов** - приведение к единому формату +7(999)999-99-99
3. **Объединение дубликатов** - удаление повторяющихся записей

## Используемые технологии
- Python 3
- Модуль re (регулярные выражения)
- Модуль csv для работы с CSV файлами

## Структура проекта
- `clean_phonebook.py` - основной скрипт
- `phonebook_raw.csv` - исходные данные
- `phonebook.csv` - результат обработки

## Как запустить
```bash
python clean_phonebook.py
